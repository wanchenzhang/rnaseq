# computational-workflows/rnaseq: Output

Paths are relative to `--outdir`. The [README](../README.md#main-outputs) explains the outputs and their interpretation in more detail.

| Directory                 | Output                                                                                   |
| ------------------------- | ---------------------------------------------------------------------------------------- |
| `cat/`                    | FASTQ files concatenated by sample; R1 and R2 remain separate for paired-end inputs      |
| `fastqc/`                 | FastQC HTML and ZIP reports for merged, untrimmed reads                                  |
| `trimgalore/` or `fastp/` | Trimmed FASTQ files and reports from the selected trimmer                                |
| `fastqc_after/`           | Independent FastQC reports on trimmed reads                                              |
| `reference/star/`         | Generated STAR index directory                                                           |
| `reference/transcripts/`  | Transcript FASTA generated by GFFREAD; absent when transcripts are supplied              |
| `star/`                   | Coordinate-sorted genome BAM, transcriptome BAM and STAR logs                            |
| `markduplicates/`         | Duplicate-marked BAMs, BAM indexes and Picard metrics                                    |
| `salmon/<sample>/`        | Salmon transcript and gene estimates                                                     |
| `tximport/`               | Transcript-to-gene mapping and merged gene and transcript matrices                       |
| `multiqc/`                | Combined HTML report and supporting data                                                 |
| `pipeline_info/`          | Timestamped execution reports, traces, timelines, DAGs, parameters and software versions |

## Expression matrices

The main expression matrix is `tximport/salmon_merged.gene_tpm.tsv`, with `gene_id`, `gene_name` and one column per sample. Other tables include gene counts, scaled counts, lengths and transcript estimates. TPM is relative abundance; the workflow does not perform differential-expression analysis.

## QC and duplicate marking

Open `multiqc/multiqc_report.html` to inspect available QC metrics across samples. Raw and trimmed FastQC reports are published separately. Fastp also supplies its own HTML and JSON reports.

Picard marks duplicates without removing them. Salmon quantifies the separate transcriptome BAM from STAR, not the duplicate-marked genome BAM. FastQC and Picard duplication estimates use different methods and should not be treated as a before-and-after comparison.

## Execution records and validation

Files in `pipeline_info/` have run-specific timestamps. Match those timestamps when comparing traces, reports and parameters. Cached tasks in a resumed run are different from newly executed tasks for performance measurements.

Running `bin/validate_outputs.py` writes `validation_report.tsv`. The script checks FASTQ records, paired-read consistency, trimming counts, TPM values and nonempty key artifacts. BAM checks do not inspect binary integrity, and merged counts are not compared with all original input records. A successful run or validation report does not establish biological validity.
